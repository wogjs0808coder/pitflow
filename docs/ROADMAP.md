# Roadmap

PitFlow의 주요 개발 단계만 정리합니다.

## 완료

### Phase 1 — 기본 서비스

- 회원가입과 로그인
- 차량 관리
- 정비 서비스
- 예상 금액
- 예약

### Phase 2 — 정비 작업

- 차량 입고
- 정비사 배정
- 정비 작업
- 부품 사용과 반환
- 작업 완료
- 정산과 정비 이력

### Phase 3 — 운영 기능

- 관리자·정비사 작업 화면
- 업무 알림
- 부품 부족 신고
- 정비 항목별 상태 관리
- 역할별 업무 흐름 정리

### Phase 4 — 원가와 재무

- 부품 판매 가격과 구매 가격 분리
- FIFO 부품 원가
- 정비사 인건비
- 작업별 수익 확인
- 운영비와 급여 관리
- 구매 가격이 없는 기존 재고 처리

### Phase 5 — 결제와 회사 자금

- Toss Payments 테스트 결제
- 고객 및 관리자 결제
- 환불과 재결제
- 현장 수납
- 결제와 회사 자금 연결
- 운영자금 / 예금 / 투자자산 관리
- 재고자산과 미결제 금액 반영
- 결제 완료 후 차량 출고 흐름

## 다음 단계

### Phase 6 — Hardening & Finalization

새로운 큰 기능을 늘리기보다 현재 기능의 완성도를 높입니다.

- 전체 사용자 흐름 재검증
- 권한과 동시 요청 점검
- 결제와 재고 예외 상황 확인
- Production 배포 확인
- 모바일 화면 보완
- 로그와 오류 처리 정리
- 코드 정리
- 포트폴리오 최종 정리

Phase 6 시작 전에 Toss 개발자센터 거래내역과 PitFlow 결제 기록을 비교하는 기능을 추가할지 별도로 결정합니다.
