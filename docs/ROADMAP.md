# Roadmap

PitFlow의 주요 개발 단계만 정리합니다.

## 완료

### Phase 1 — 기본 서비스

- 회원가입과 로그인
- 차량 관리
- 정비 서비스
- 예상 금액
- 예약

### Phase 2 — 정비 작업

- 차량 입고
- 정비사 배정
- 정비 작업
- 부품 사용과 반환
- 작업 완료
- 정산과 정비 이력

### Phase 3 — 운영 기능

- 관리자·정비사 작업 화면
- 업무 알림
- 부품 부족 신고
- 정비 항목별 상태 관리
- 역할별 업무 흐름 정리

### Phase 4 — 원가와 재무

- 부품 판매 가격과 구매 가격 분리
- FIFO 부품 원가
- 정비사 인건비
- 작업별 수익 확인
- 운영비와 급여 관리
- 구매 가격이 없는 기존 재고 처리

### Phase 5 — 결제와 회사 자금

- Toss Payments 테스트 결제
- 고객 및 관리자 결제
- 환불과 재결제
- 현장 수납
- 결제와 회사 자금 연결
- 운영자금 / 예금 / 투자자산 관리
- 재고자산과 미결제 금액 반영
- 결제 완료 후 차량 출고 흐름

### Phase 6 — 계정과 업무 UX

- 계정 정보 변경·복구, 관리자 계정 관리
- 예약·작업·정산 업무 흐름 개선
- 업무 알림, Toast 및 반응형 화면 개선
- 로컬 회귀 검증과 최종 코드 점검

## 다음 단계

### 배포 후 최종 확인

- Production 역할별 업무 흐름과 Toss 테스트 결제 재검증
- 실제 모바일 기기에서 화면·알림·달력 확인
- CI와 배포 상태 확인 후 v1.0.0 결정
